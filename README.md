# Blue Glitch Slots (Fabric 1.21.11, client-side)

Every item **without** an enchant glint gets a blue glitch animation in its slot:
a faint blue glow, flickering glitch tears, and a bright scan bar that runs across the
hotbar (and inventory rows) from slot to slot. Enchanted items keep their normal glint,
which the **Blue Glitch** resource pack turns blue.

Client only: works on any server, nothing needed server-side. Needs Fabric API.

Tweak speed/colors at the top of `GlitchEffect.java`.
